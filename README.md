## 🚀 Features

- **Modern UI:** Clean layout with a professional visual style.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Project Gallery:** Showcases six selected graphic design projects.
- **Category Filters:** Filter projects by Food & Ads, Digital Design, and Branding.
- **Interactive Navigation:** Smooth scrolling and mobile-friendly navigation.
- **Canva Integration:** Direct links to view the original designs.
- **About Section:** Introduction to my design interests and creative approach.
- **Contact Section:** Email contact button and copy-email functionality.
- **Subtle Animations:** Hover effects and transitions for an engaging experience.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Styling, layouts, animations, and responsive design
- **JavaScript** — Project filtering, mobile navigation, and interactive functionality
- **Canva** — Creation of graphic design projects
- **Netlify** — Website deployment and hosting
- **Google Fonts** — DM Sans and Space Grotesk
